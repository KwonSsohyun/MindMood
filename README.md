## 👀 프로젝트 소개
- **감정 해소** : 스트레스를 줄이고 감정을 표현하세요.
- **자기 성찰** : 감정을 기록하여 자신을 깊이 이해하세요.
- **감정 추적** : 감정 변화를 쉽게 파악하세요.
- **자아 정체성** : 우선순위를 통해 나를 알아가세요.

<br/>

## 🖥️ 화면 설계
1. **메인 - 감정 달력**
   - 감정 이모지 표현 (최고, 좋음, 보통, 안좋음, 많이 나쁨)
   - 일기쓰기 / 일기보기 버튼

2. **서브 - 일기 기록** 
   - (사건, 감정, 행동, 결과, 제안)

   1) **오늘의 기분 점검**
      - 감정 강도 : 1-10점으로 평가하세요.
      - 감정 이모지 : 기쁨, 행복, 설렘, 우울, 슬픔, 짜증, 후회, 분노, 불안, 중립 

   2) **사건 기록**
      - 주요 사건 : 오늘의 사건을 1-2문장으로 작성하세요. (시간, 장소 포함)
      - 함께한 사람 : 친구, 가족, 연인, 동료, 상사, 부하, 친척, 지인, 혼자, 직접 입력

   3) **감정 탐구**
      - 주요 감정 : 사건과 관련된 감정을 선택하세요.
      - 감정 이유 : 그 감정을 느낀 이유와 상황을 적어보세요.

   4) **행동/반응 분석**
      - 행동 기록 : 감정을 표현한 방식이나 행동을 적어보세요.
      - 행동 영향 : 해당 행동이 내 기분에 미친 영향을 적어보세요.
      - 미표현 이유 : 감정을 표현하지 않은 이유를 적어보세요.

   5) **결과 평가**
      - 결과 : 이 사건이 가져온 결과를 적어보세요.
      - 원하는 행동 : 비슷한 상황에서 앞으로 어떻게 행동하고 싶은지 적어보세요.

   6) **자기 제안**
      - 느낀 점과 다짐 : 자신에게 해주고 싶은 긍정적인 메시지나 다짐을 적어보세요.

3. **서브 - 일기 목록**
   - 리스트 형식

4. **서브 - 일기 상세**
   - 수정 (취소, 완료) / 삭제

5. **서브 - 감정 차트**
   - 월간 기분 분석 (원그래프, 선그래프)
   - 감정 이모지 갯수
